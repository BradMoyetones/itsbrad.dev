## Overview

This project was developed in response to the need for better control over the employee lunch benefit at **Parque Jaime Duque**. Previously, the registration and planning process was manual and inefficient, leading to increased operational overhead and limited forecasting capabilities.

The goal was to digitize the registration process, improve transparency, and enable the Gastronomy team to plan meal preparation more accurately.

## Key Features

- **Daily Registration**: Employees register daily for lunch before 10:00 a.m. to be considered in that day's meal plan.
- **Admin Dashboard**: The admin panel allows the Gastronomy team to view real-time data, apply filters by department or day, and export detailed reports.
- **Preparation Forecasting**: The system automatically estimates how many meals should be prepared each day based on real-time registration data.
- **Meal Claim Module**: Allows employees to submit claims if issues occur, with built-in workflows for resolution and tracking.
- **Statistics & Reports**: Includes visual dashboards to monitor usage over time, helping HR and admin teams evaluate benefit engagement.

## Technologies Used

- **PHP (Slim Framework)**: Lightweight backend for routing and logic handling.
- **Eloquent ORM**: For database interactions and model abstraction.
- **React + TypeScript + Vite**: For building a fast and modular frontend admin panel.
- **MySQL**: As the relational database for storing users, registrations, and analytics.
- **Tailwind CSS**: For modern and responsive UI styling.
- **Recharts**: For dynamic visualizations in the analytics dashboard.

## Challenges and Learnings

A key challenge was building a user-friendly experience for non-technical staff while ensuring accurate data processing and scalable logic. Collaborating directly with the Gastronomy and HR teams helped shape workflows that aligned with real-world needs.

The forecasting logic also required building time-sensitive registration logic to influence real-time reporting without relying on manual intervention.

## Outcome

The application is now fully adopted by internal staff and has become an essential part of the park’s daily operations. It significantly reduced manual work, optimized meal preparation, and improved data visibility for decision-making.

The system continues to support growing internal needs and serves as a foundation for future integrations across departments.
