## Acerca de

Noesis es una **plataforma de publicación moderna** construida para desarrolladores y escritores que desean compartir reflexiones, historias o ensayos. Cuenta con una estructura limpia, **MDX-first**, con un potente stack tecnológico:

* **Next.js App Router**
* **PostgreSQL** a través de Neon
* **Prisma ORM**
* **NextAuth.js** con Google y credenciales
* **Tailwind CSS** y **shadcn/ui**
* **Plate.js** para la edición visual
* **Server Actions**

El proyecto es compatible con características sociales (como seguidores y "me gusta"), categorización de publicaciones, hashtags y verificación de correo electrónico.

### Opciones de autenticación

<CodeBlock compact marginBottom="16" codes={[
  {
    code: `import GoogleProvider from "next-auth/providers/google"
import CredentialsProvider from "next-auth/providers/credentials"
import { PrismaAdapter } from "@auth/prisma-adapter"
import { db } from "@/lib/prisma"
import { addDays, addMinutes } from "date-fns"
import { compare } from "bcrypt"
import { encode } from "next-auth/jwt"
import { sendVerificationEmail } from "./mail/email-service"

const adapter = PrismaAdapter(db)

export const authOptions = {
  adapter,
  providers: [
    GoogleProvider({
      clientId: process.env.GOOGLE_CLIENT_ID!,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
    }),
    CredentialsProvider({
      name: "Credentials",
      credentials: {
        email: { label: "Email", type: "text" },
        password: { label: "Password", type: "password" },
      },
      async authorize(credentials) {
        if (!credentials?.email || !credentials?.password) return null

        const user = await db.user.findUnique({
          where: { email: credentials.email },
        })

        if (!user || !user.hashedPassword) {
          throw new Error("Invalid credentials.")
        }

        const isValid = await compare(credentials.password, user.hashedPassword)
        if (!isValid) {
          throw new Error("Incorrect password.")
        }

        return user
      },
    }),
  ],
  session: { strategy: "database" },
  callbacks: {
    async jwt({ token, account }) {
      if (account?.provider === "credentials") {
        token.credentials = true
      }
      return token
    },
    session({ session, user }) {
      if (user?.id) session.user.id = user.id
      return session
    },
    async signIn({ user }) {
      if (!user.emailVerified && user.email) {
        const token = crypto.randomUUID()
        const expires = addMinutes(new Date(), 10)

        await db.verificationToken.create({
          data: {
            identifier: user.email,
            token,
            expires,
          },
        })

        await sendVerificationEmail(user.email, token)
      }

      return true
    },
  },
  jwt: {
    encode: async function (params) {
      if (params.token?.credentials) {
        const sessionToken = crypto.randomUUID()
        const createdSession = await adapter?.createSession?.({
          sessionToken,
          userId: params.token.sub!,
          expires: addDays(new Date(), 30),
        })

        if (!createdSession) throw new Error("Failed to create session")

        return sessionToken
      }

      return encode(params)
    },
  },
}`,
    language: "ts"
  }
]} />
