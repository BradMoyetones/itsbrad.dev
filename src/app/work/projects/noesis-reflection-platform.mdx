## Overview

**Noesis** is a modern, open platform designed for publishing personal reflections, manifestos, and deep written thoughts. Inspired by digital minimalism and philosophical aesthetics, the project goes beyond software—it's a technical and creative manifesto.

## Key Features

- **Rich Text Editor**: Built using Plate.js (based on Slate), allowing creators to write with blocks like quotes, headers, lists, images, and code with ease.
- **User Profiles & Discovery**: Authors can customize their public profile and explore writings by others through smart filters and tags.
- **Points of View System**: Users can follow authors and receive curated feeds, encouraging thoughtful interaction and feedback.
- **Content Organization**: Posts can be organized by collections, categories, and tags, making it easier to manage and explore content.
- **Post Ownership & IP Tools**: Measures like post signing and licensing (planned) provide creators with tools to protect and manage their intellectual property.

## Technologies Used

- **Next.js**: React framework for routing, performance, and rendering.
- **Plate.js**: Advanced rich-text editor built over Slate.js.
- **Prisma ORM**: Type-safe database access with PostgreSQL.
- **Neon.tech**: Scalable serverless PostgreSQL backend.
- **Shadcn/UI**: Clean, accessible, and modern UI components.
- **Tailwind CSS**: Atomic styling for a consistent, clean interface.
- **Lucide Icons**: Elegant, open-source SVG icons.

## Challenges and Learnings

Creating a platform that feels equally good for both writers and developers posed unique challenges. Balancing a fluid writing experience with modularity and performance required testing multiple rich text editors. Eventually, Plate.js stood out for its flexibility and extensibility.

Design-wise, the focus was on keeping a minimalist aesthetic while still giving users control and expression through UI customizations. The backend architecture was made fully extensible to allow self-hosted forks or plug-ins.

## Outcome

The app is in active development, but already supports full post creation, user accounts, post discovery, and a clean writing experience. It’s a base not only for personal expression, but for building communities around writing, thought, and creative freedom.
