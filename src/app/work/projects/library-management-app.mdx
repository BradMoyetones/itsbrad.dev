## Overview

This internal tool was developed to improve the management of Parque Jaime Duque’s internal library, which previously relied on manual Excel spreadsheets to track loans and returns.

The goal was to offer a system where employees could browse available books, check summaries, and manage loan activity through a centralized digital platform — reducing administrative friction and improving tracking accuracy.

## Key Features

- **Book Catalog**: Staff can browse the full list of books, view availability status, summaries, and descriptions before borrowing.
- **Loan Management Module**: Admin users can register new loans, process returns, and automatically update book statuses in real time.
- **Overdue Tracking**: The system flags overdue returns and highlights pending items to ensure accountability.
- **Inventory Control**: Admins can add new books, update metadata, and remove inactive titles directly through the interface.
- **Notifications and Visual Status**: Clearly indicates book status (available, loaned, overdue) to both users and administrators.

## Technologies Used

- **PHP (Slim Framework)**: Backend logic for book, loan, and user operations.
- **Eloquent ORM**: To handle database models and relationships.
- **React + TypeScript + Vite**: For building a responsive and user-friendly frontend interface.
- **MySQL**: As the main database for storing books, user data, and loan history.
- **Tailwind CSS**: For styling and UI consistency.

## Challenges and Learnings

One of the key challenges was designing a system that would feel intuitive to a wide range of users, some of whom had little experience with digital tools. A clean, simple interface was critical for encouraging adoption.

On the admin side, it was important to ensure that the system could easily scale with new books, multiple loans, and rule logic for returns — all while reducing the cognitive load for the librarians.

## Outcome

The platform has greatly improved the library experience for collaborators. Employees can now discover and request books more efficiently, and the HR and administrative teams have full visibility into book usage and return compliance.

This tool not only modernized an outdated manual process, but also encouraged more active use of the park’s educational resources by making them more accessible.
