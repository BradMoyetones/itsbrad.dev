## Overview

This internal platform was built to manage the weekly and rotational schedules of security guards across Parque Jaime Duque. Before this solution, scheduling was managed manually — resulting in confusion, constant inquiries, and inefficiencies.

The application allows for dynamic scheduling and provides a personalized dashboard for each guard to check their assigned posts and hours.

## Key Features

- **Shift Programming Module**: Admins can create, edit, and assign custom time blocks to guards, defining roles, areas, and time ranges.
- **Personalized Guard View**: Each guard logs in to see their current and upcoming assignments via a clear and mobile-friendly interface.
- **Custom Schedule Templates**: Enables the creation of reusable templates to simplify recurring shift patterns.
- **Weekly Overview**: Displays a summarized view of the entire week’s schedule for quick adjustments and visual clarity.
- **Role-Based Access**: Guards can only view their assignments, while admins have full control over all schedules and users.

## Technologies Used

- **PHP (Slim Framework)**: To manage scheduling logic, authentication, and API routing.
- **Eloquent ORM**: For database models, user-role management, and shift assignments.
- **React + TypeScript + Vite**: Built the frontend with a responsive interface tailored for desktop and mobile.
- **MySQL**: Used to store shifts, users, roles, and schedules with high data integrity.
- **Tailwind CSS**: For clean and efficient UI design.

## Challenges and Learnings

The main challenge was ensuring flexibility in scheduling without compromising clarity. Shifts in the park vary by hour, location, and day, so the system had to be modular enough to support that without overwhelming the admins.

Providing a frictionless experience for security guards — many of whom had never used a scheduling app before — required careful interface planning and usability testing.

## Outcome

The scheduling system significantly reduced confusion and manual communication regarding shifts. Guards now check their weekly rota independently, and updates can be made on the fly by the admin team.

This has led to a smoother operational flow, increased punctuality, and better shift planning throughout the park.
